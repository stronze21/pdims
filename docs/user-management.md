# User Management

## Reset a password

Users with `view-settings` permission can reset a password from **User Management**.

1. Find the account using the search or filters.
2. Select **Reset password** beside the account.
3. Confirm the reset to the default password shown in the confirmation message.
4. Ask the user to sign in with the default password and change it from their profile.

Protected Super Admin accounts cannot be reset from this page.
